# POE2 新手 Wiki

从[首页](index.html)进入，按「新手起步 → 开荒奖励 → 装备与交易 → 卡关排查 → 异界路线」阅读。

## 本地更新

1. 编辑对应的 `.md` 文件。
2. 首次运行 `npm install`，之后运行 `npm run build`。
3. 提交 Markdown、HTML、CSS 与 JavaScript 文件。`index.html` 是网站入口。

静态页面可发布到 GitHub Pages：仓库 Settings → Pages → Deploy from a branch → `main` → `/ (root)`。文内部分截图引用外部网站，显示图片需要网络连接。
