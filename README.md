# POE2 新手 Wiki

在线阅读：[POE2 中文新手 Wiki](https://windrunner0707.tech/poe2-newbee-wiki-cn/)

从[首页](index.html)走八篇必读主线：第一次游玩 → 新手起步 → 角色面板 → 开荒奖励 → 看懂装备 → 装备与交易 → 战役结束到第一张图 → 异界路线（含前十图装备升级计划）。做装备、找 BD、卡关排查、名词黑话和乐趣避雷是按需查阅专题。

## 本地更新

1. 编辑对应的 `.md` 文件。
2. 首次运行 `npm install`，之后运行 `npm run build`。
3. 提交 Markdown、HTML、CSS 与 JavaScript 文件。`index.html` 是网站入口。

网站由 GitHub Pages 从 `main` 分支根目录发布。`images/` 中的教学示意图随网站发布；文内部分游戏截图引用外部网站，显示需要网络连接。
