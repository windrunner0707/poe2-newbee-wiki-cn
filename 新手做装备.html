流放之路 2：新手做装备

适合推战役到刚进入异界、想亲手做一件过渡装备的玩家。核对日期：2026-10-09；以 0.5 系列为背景。通货、精华和赛季制作规则可能改变，点击材料前先读游戏内物品说明。本文的例子讲判断方法，不保证出现指定词缀或数值。

如果还不知道要补什么，先看装备与交易的换装顺序。制作前也可以到官方交易站看同联盟成品价格：做装备是解决问题的一种方法，买到合适成品也可以。

若“底材”“要求等级”“物品等级”和“随机词缀”还分不清，先用装备提示框图解读一件手中的装备，再回本页操作。

先决定：捡、买，还是自己做

当前情况 推荐动作 原因
地上或商人处已有一件能明显补短板的装备 直接穿，复查角色面板 不必为了“亲手做”消耗材料
缺一项常见属性，手里有合适底材和少量材料 尝试做一件过渡装 目标简单，做出够用的就停
同联盟有价格可接受、属性完整的成品 先比较购买成本 自己制作的结果有随机性

先写目标：我要补___；这件装备必须保留___；最多花___；做到___就停。 例如“补火抗，不能让主技能因属性不足变灰；最多用手头少量基础通货；穿上后能稳定完成当前地图就停”。预算用自己当前联盟的价格衡量，不写死通货比例。

第一步：选对底材

  1. 确认部位与武器类型。主技能要求某类武器，就不要在另一类武器上投入。防具先看基础防御类型、属性要求、移动速度等与你的角色是否匹配。
  2. 看物品等级与词缀。物品等级影响可出现的词缀范围；想做的属性是否能出现在该部位、该底材和该等级上，先到流放2编年史查词缀，再以当前游戏内说明核对。战役过渡装不必为了最高物品等级耽误进度。 鼠标悬停物品时按 Alt 可查看物品等级；它与角色装备所需等级不是同一个数。底材自带属性、随机词缀和符文提供的属性也要分开看，免得误以为某条属性能被普通通货随机出来。
  3. 看已有属性。普通、魔法、稀有装备能使用的材料不同。已有两项对你有用的词缀的黄装，可能比一件“高级白底材”更接近可穿成品。
  4. 留意无法轻易撤销的状态。使用会腐化物品或改变关键词缀的材料前，先读提示；正在穿的唯一一件能用装备，最好不要直接拿来试验。

新手优先级：能穿、能用技能、补当前短板，比追求某个理论上的顶级底材更重要。

第二步：认识手里的材料

以下只列新手最常碰到的用途。材料名称相似、等级不同，适用的物品稀有度和结果也可能不同；把游戏内说明当作最终操作说明。

0.5 更新加入了合金、更多符文及相关制作功能；这些材料有各自的解锁条件和效果，不要把它们当成任意装备通用的“补一条词缀”按钮。初次制作先用已看懂说明的基础材料。具体版本变化见官方 0.5.0 更新说明。

两条可以照着尝试的基础路线

路线 A：从白装逐步做。对白装使用蜕变石，得到一条随机词缀；这条若已经有用，再考虑用增幅石给魔法装备加第二条。魔法装备值得保留时，才考虑用富豪石升为稀有装备并增加一条；稀有装备还有空位、且下一步成本合适时，再考虑用崇高石加随机词缀。每一步都可能出不想要的属性，不是必须走完整条路线。通货说明

路线 B：围绕精华做。先找已有一条有用词缀的魔法底材；核对所持精华的适用稀有度、部位与保证添加的属性，再决定是否用它升级为稀有装备。当前普通层级的精华与高阶、完美精华作用不同，尤其不要把“替换一条随机词缀”误读成“只替换不想要的词缀”。精华说明

若想用点金石快速取得稀有装备，注意它会生成随机词缀，不会保留原魔法装备上已经满意的词缀；因此别把它当作上述两条路线的无损下一步。点金石说明

第三步：每用一次材料，都做一次停手判断

  1. 动手前拍下或记下原装备。记录实际火、冰、闪抗性，生命／能量护盾、关键属性，以及技能是否可用。
  2. 只选一种明确目标。防具可先补抗性或生存；武器先补主技能真正使用的伤害属性。不要同时要求每一条词缀完美。
  3. 读材料说明并确认预览。确认物品稀有度、目标部位、会增加、替换还是重掷词缀；再点击使用。
  4. 结果够用就停。穿上装备回角色面板验证，去原本卡住的同类内容试一次。若结果使技能无法使用、抗性缺口扩大或防御下降，先别继续往上砸材料。
  5. 未达目标时重新比较成本。把已经花掉的材料视为已花成本；下一步只比较“再做一次的成本”和“现在买或换另一底材的成本”。

停手规则：满足目标就停；下一步材料比同类成品还贵就停；好词缀可能被覆盖却没有备选装备时也停。不要因为已经投入过材料而继续追。

实例一：做一件补抗性的过渡防具

情境：进入异界后火抗明显低，生命也偏少。手里有一件等级要求能满足、防御类型合适的防具；当前身上这件还提供了主技能需要的属性。

  1. 先看旧装备和角色面板，写下必须保留的属性要求、火抗缺口与最低可接受的生命／能量护盾。
  2. 查手中底材已有词缀。如果它已有你需要的火抗和一项生存属性，先试穿比较，可能不必制作。
  3. 若是空白底材，选适用且价格可接受的基础通货或精华，按材料说明进行一步制作。每一步后看实际生成的词缀，不预设下一步必然出现火抗。
  4. 出现能补火抗、又不破坏技能要求的结果就停。若仍缺一点抗性，也可以检查戒指、护符等其他部位，不必强迫这一件防具承担所有缺口。
  5. 穿上后核对三种元素抗性和主要防御，打一张原本能完成的地图。如果整体变差，换回旧装备；剩余预算拿去比较成品。

这件装备的成功标准是“稳定可用”，不是六条词缀都漂亮。

实例二：做一把能提升主技能的过渡武器

情境：清怪明显变慢，旧武器基础类型落后。你找到了主技能允许使用的新武器底材。

  1. 先读主技能的伤害来源：是使用武器攻击，还是主要依赖技能等级、法术相关属性或其他机制。不同技能不能只比较武器面板数字。
  2. 确认新底材的武器类型、属性要求和可用词缀。用少量材料制作并查看结果；如果第一步没有得到对主技能有用的属性，不要自动追加昂贵材料。
  3. 把新旧武器分别装备，在同一类怪和首领上测试伤害、消耗和技能可用性。新武器若导致失去抗性或属性，也计入实际成本。
  4. 若已有接近预算的成品武器，就用官方交易站筛正确联盟与关键属性进行比较，再决定是否继续制作。

什么时候再学进阶制作

当你已经能稳定刷图，能说清目标词缀、底材与物品等级，并愿意承担多次失败成本，再研究预兆、合金、特殊符文、品质和其他机制。查资料时先看材料自己的说明及官方版本公告，再用编年史查询词缀；操作流程可先在工具里模拟，但模拟结果不代替游戏内核对。

如果你是交易联盟玩家，进阶制作前先记录：底材成本 + 每次材料成本 + 预计尝试次数，然后与同联盟成品报价比较。单人自力玩家则以材料库存和能否稳定推进为停手依据。

做完后的检查清单

  • 装备要求满足，主技能仍能正常使用。
  • 角色面板的火、冰、闪抗性没有意外下降。
  • 生命／能量护盾和主要防御整体变好，或至少没有为一点伤害付出过高代价。
  • 在原本卡住的内容中实际测试过。
  • 已记录这次花费，下次知道该继续制作还是买成品。
