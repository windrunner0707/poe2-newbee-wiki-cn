流放之路 2：名词、黑话与中英对照

查词页，不用从头背。不同中文客户端、社区与版本的译名可能不同；在交易站或英文资料里搜不到中文词时，试试英文名。这里的“黑话”是玩家常用简称，不一定是游戏内正式名称。核对日期：2026-10-09。

先分清三种“点”和三种“图”

↔ 左右滑动查看完整表格
中文／黑话 英文 一句话解释
普通天赋点 Passive Skill Point 升级等途径取得，分配在角色天赋树。
武器组天赋点 Weapon Set Passive Skill Point 可给不同武器组配置天赋；开荒奖励统计的是这类战役奖励。
升华点 Ascendancy Skill Point 完成合适试炼后取得，分配在升华职业树；不计入武器组点数。
战役区域／章节 Campaign Area / Act 推主线时进入的区域。
地图／刷图 Map / Mapping 进入异界后用引路石开启并反复完成地图；“刷图”通常指重复这个过程。
异界图鉴／异界树 Atlas / Atlas Passive Tree 前者是终局地图路线，后者是影响地图内容与掉落的天赋树。

角色与装备

↔ 左右滑动查看完整表格
中文／黑话 英文 新手该怎么理解
BD、流派 Build 技能、天赋、装备与防御方式组合成的角色方案。
主技能 Main Skill 当前承担主要伤害或清怪任务的技能。
辅助宝石 Support Gem 放在某个技能的辅助插槽里，改变该技能效果；先查是否真的生效。
精魂／预留 Spirit / Reservation 部分持续效果使用的资源；持续技能开不了时看剩余精魂。
底材 Base Item / Base Type 装备本身的类型与基础数值；做装备先选合适底材。
物品等级 Item Level / ilvl 影响能出现的词缀范围，和“要求角色等级”不同。
词缀 Modifier / Mod 装备上增加生命、抗性或伤害等属性的条目。
自带属性／固定属性 Implicit Modifier 由底材等来源提供，与普通随机词缀分开看。
前缀／后缀 Prefix / Suffix 随机词缀的两类位置；制作时决定还有没有空间加属性。
抗性补满／满抗 Resistance Cap 对应抗性达到角色当前上限；看角色面板实际值。
腐化／俗称黑化 Corrupted / Corruption 物品经腐化机制改变后的状态；进一步制作可能受限制，使用前读材料说明。它与本文标题里的“黑话”不是一回事。

通货、交易与异界

↔ 左右滑动查看完整表格
中文／黑话 英文 新手该怎么理解
通货 Currency 既可用于改造物品，也常用于交换；游戏金币另算。
崇高石／E Exalted Orb / Ex 常见制作与交易通货；不要看到一件黄装就随手使用。
神圣石／D Divine Orb / Div 交易中常用的较高价值通货；价格随联盟变化。
自力模式 Solo Self-Found / SSF 不与其他玩家交易，装备主要靠自己的掉落与制作。
过滤器 Item Filter / Loot Filter 调整地面掉落显示；刚开图先选宽松版本。
引路石 Waystone 用来在地图装置开启异界地图的物品。
石板 Precursor Tablet / Tablet 在地图装置中为地图加入额外内容，通常比基础开图更后学。
高塔／要塞 Tower / Fortress 异界图鉴里的不同目标；按异界路线逐步推进。
上强度、叠投入 Juicing 用引路石词缀、石板等增加地图难度和预期产出；新手先学稳定完成。
毕业装 Best-in-slot / Endgame Gear 社区说的高预算终局装备，不是开第一张图的门槛。

看到黑话时的阅读方法

例如“先补满抗，再刷低 T 图，攒 E 换武器”：它的意思是先看角色面板的元素抗性，在能稳定完成的低阶地图积累可用通货或材料，然后升级武器。这里的 T 来自 Tier（等阶），不是要求你立刻挑战最高等阶。

如果一个攻略只写“毕业、满配、每小时几 D”，却没有给战役或刚进异界的过渡方案，先看怎样判断 BD。遇到陌生缩写，先找它在游戏内对应的物品、技能或界面，再决定是否照做。
